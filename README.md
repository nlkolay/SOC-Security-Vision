# SOC Security Vision 5

Визуальная архитектурная карта для SOC / центра мониторинга и реагирования на инциденты.

## Что это за проект

Этот репозиторий содержит статическую HTML-страницу с интерактивной схемой архитектуры Security Operations Center (SOC), включая:

- наблюдение и сбор телеметрии;
- коридоры безопасности и управления инцидентами;
- домены и роли в экосистеме ЦОД;
- поток данных, SIEM, SOAR, IDS/IPS и прочие компоненты;
- наглядную документацию в формате UML/architectural blueprint.

Основной входной файл: `index.html`.

Полная карта архитектуры: `soc_security_vision_5_uml_blueprint.html`.

## Структура репозитория

- `index.html` — стартовая landing-page, входная точка проекта;
- `soc_security_vision_5_uml_blueprint.html` — основная схема SOC архитектуры;
- `README.md` — описание и инструкции по запуску и деплою.

## Запуск локально

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/nlkolay/SOC-Security-Vision.git
   cd SOC-Security-Vision
   ```

2. Откройте `index.html` в браузере или запустите локальный сервер:

   ```bash
   python3 -m http.server 8000
   ```

3. Затем откройте в браузере:

   ```text
   http://localhost:8000
   ```

## Развертывание на GitHub Pages

Репозиторий настроен для автоматического деплоя в GitHub Pages через GitHub Actions.

### Что нужно сделать в GitHub

1. Откройте репозиторий на GitHub.
2. Перейдите в `Settings` → `Pages`.
3. В поле `Source` выберите `GitHub Actions`.
4. После этого запустите workflow вручную или просто сделайте push в `main` — деплой начнётся автоматически.

### Автоматический деплой

В репозитории уже есть workflow для публикации статических HTML-файлов:

- `.github/workflows/deploy-pages.yml`

После первого запуска сайт будет доступен по адресу вида:

```text
https://<username>.github.io/SOC-Security-Vision/
```
